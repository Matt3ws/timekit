# Changelog

Each release takes its notes from the `## <version>` section here.

## 0.2.0

- TimeKit updates itself: it checks for a new release on start and once a day, and **Update to <version>** in the sidebar installs it and restarts. Settings → Updates shows the installed version, has **Check now**, and can turn the automatic check off.
- The Mac app is signed with TimeKit's own certificate, the same for every release.
- Install this version by hand once; updates after it install themselves.

## 0.1.0

- First release: time tracking, invoices, subscriptions and bookkeeping on Mac and Windows.
- Optional sync between machines through Turso.
